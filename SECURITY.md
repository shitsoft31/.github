# Security Policy

Thank you for helping keep ShitSoft projects secure.

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub Issue**.

Instead, report it privately by emailing:

**[shitsoftofficial@gmail.com](mailto:shitsoftofficial@gmail.com)**

Please include as much information as possible:

* Project name
* A description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Proof of concept (if applicable)
* Suggested mitigation (optional)

## Response Process

After receiving your report, we will:

1. Acknowledge receipt as soon as possible.
2. Investigate the issue.
3. Work on a fix if the report is valid.
4. Coordinate disclosure when appropriate.

We appreciate responsible disclosure and ask that you do not publicly disclose security vulnerabilities until a fix has been released or we have agreed on a disclosure timeline.

Thank you for helping improve the security of the ShitSoft community.
